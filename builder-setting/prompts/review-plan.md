# Review a plan

Use at stage 3, when the person reads `PLAN.md`. `C3 Interrogate the claim`. The person can use it alone or give it to a second session that did not write the plan.

```text
Read BRIEF.md, BUILDER-SPEC.md and PLAN.md.

For each decision in PLAN.md:
1. Restate it in one sentence.
2. Name the sentence in BRIEF.md it serves. If there is none, say so.
3. Say which layer it puts the rule in. Flag any rule placed in the shim
   or the page.
4. Say whether the named test could fail if the decision were wrong.
   If it could not, say what test could.

Then list anything in BRIEF.md that no decision covers, and any open
question whose answer would change the build order.

Do not rewrite the plan. List the problems first.
```

The plan goes back to stage 2 with the list. The person answers the open questions by number.
