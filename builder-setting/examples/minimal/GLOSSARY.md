# Glossary

The source of truth for what each word in the bounded counter means. The format is described in the template's `GLOSSARY.md`.

### Count

The number the counter shows. It starts at zero and stays between zero and the maximum.

Not: score, tally, total

### Maximum

The highest count the counter reaches. It is `max` in `data/counter.json`.

Not: limit, cap, ceiling

### Step

How much one press of Add or Remove changes the count.

Not: increment, amount
